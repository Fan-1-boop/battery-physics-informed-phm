# v12：两标注电芯交叉可靠性约束的残差校准——执行前开发集协议（2026-10-12）

## 性质与时间顺序

本文创建于 **v12 真实数据计算之前**，用于固定**本轮新增方法与报告规则**；但 v8–v11 已经多次使用同一 47 个 XJTU 目标电芯进行选择与诊断，因此**本协议不构成首次接触数据的正式预注册，也不构成独立验证**。已有 3C 负迁移与四分位方法的后验选择均明确标记为开发集先验。

## 研究问题与唯一候选机制

固定旧 RW8 源模型、原六个逐循环充电统计输入、47 个目标电芯、v8 电芯级五折、v9 随机种子、目标训练池每次选择 k=2 电芯、N=10/20/30 个早期容量标签。探索能否通过**仅对两块已标注电芯进行留一电芯交叉校准**估计一个全局收缩强度，减少校准负迁移。

保留与 v10 完全一致的选择策略：`random`（每折5次）与 `pred_quartiles`（每折1次）；不添加新的选样策略或换目标电芯。

### 固定具体算法：两电芯 LOCO（leave-one-cell-out）ridge 残差收缩

对于每个训练折/选择重复/标签预算 N，令每块电芯的前 N 循环残差为
`r_j = y_j - f_RW(X_j)`；拟合 `g_all` = 2个标注电芯上 Ridge(alpha=10, RW 源标准化，电芯等权)，是 v10 原有 `source + residual Ridge`。

1. 分别在标注电芯1上单独拟合相同 Ridge 残差 `g_{-2}`，并预测电芯2的前 N 残差；在电芯2上单独拟合 `g_{-1}`，并预测电芯1。
2. 对每块**仅已标注**电芯 j 的 LOCO 预测残差 `d_j = g_{-j}(X_j)`，定义
   `A = sum_j mean(d_j * r_j)`，
   `B = sum_j mean(d_j**2)`。
3. 不做额外超参搜索；直接计算 `lambda = clip(A/B, 0, 1)`；若 `B<=1e-20` 固定 `lambda=0`。
4. 最终估计 `Q_hat = f_RW(X_test) + lambda * g_all(X_test)`。lambda 与模型系数只从选中的2块目标训练电芯的前N真实容量标签及充电特征获取；外层测试电芯的任何特征/标签不得参与选样、lambda拟合或调参。
5. 这等价于最小化两块标注电芯内**留一电芯残差预测**的电芯等权 MSE；终测报告的全轨迹 MAE 仍为 mAh。lambda 属于内部可靠性估计，不是测试误差最优权重。

**对照**：source-only(lambda=0)，v10原始残差Ridge(lambda=1)，v10两电芯均值offset，以及新增LOCO shrinkage；源模型与测试折完全固定。报告lambda分布、0/1边界占比、和逐电芯负迁移。N30作为本轮主要诊断预算，N10/20为敏感性；不能根据N结果事后换主要终点。

## 预先固定的主要读数

- 5个工况分别的电芯等权全寿命容量MAE；五工况等权宏MAE；
- 3C 15电芯：相对 source-only 变差电芯数量，及对 v10 Ridge 校准的平均误差差异（主关注，但非新数据独立检验）；
- 与随机策略的差异必须保持五个选择重复每个被测电芯内等权平均，且不能当作额外独立电芯；
- 总成本：2块目标训练电芯各 N 容量标签，20/40/60条，每折记录ID及真值条数；
- stratified target-cell paired bootstrap 10000 次、种子 `20261212`，效应 = 旧 Ridge MAE − 新收缩 MAE（正=新法更好），仅描述性，忽略训练池交叠、共同源模型与开发后验选择的相关性；
- 输入原始 CSV SHA、源模型参数验证、v10逐值一致性（MAE容差1e-6mAh）、随机选择与所有测试折ID保持不变；
- 即使表现不佳也必须归档完整输出，不能追加别的lambda方法后仅报告改善版本。

## 重要实施边界

- RW 是**随机运行工况**，不是 Che 的随机片段。XJTU 数据中的六个充电统计特征与放电容量是观测量，不是电极物理真实状态。
- v10/v12 N=10 的无标签选样仍观察到**第12循环**充电特征，因此若真实容量标签未预先留存，不能在第10循环结束时已经完成全部选样并逆向采集前10循环容量；必须明确此时间顺序限制。N>=20则可在第12循环后决定标注，但若早期容量需要专门的诊断测试，仍须事先保存可回溯的原始记录。
- 本研究所有 target test 轨迹的全寿命容量标签仅作结束后评价，不用于调参；所有结果是容量MAE(mAh)，不是SOH百分比。
- v12 LOCO 是由 LOOCV 和校准收缩既有思想组成的**适配实现**，不能声称发明交叉验证、Ridge或收缩理论本身，亦不能称为 Che 原网络的直接改进或精确复现。

## 判定

若 LOCO 不能同时有效减少 3C 负迁移且没有严重损害其他目标域性能，应当归档其失败与原因，不将其写作得到验证的论文核心创新。任何最终创新性的强主张必须在此前未参与方法开发的独立新目标电芯/外部数据集上另行确认。
