# v10 固定循环标注预算实验协议（2026-10-12，执行前记录）

**实验地位：开发集敏感性分析，而非独立确认性实验。** Random 与 Pred-quartiles 的选择规则已在 v9 的相同 47 电芯和折中比较并被事后选出；本实验只研究标注成本与校准器，不可将相同测试集上改进称为独立泛化确认。

- RW 源 8 电芯、公开数据固定 commit `cc3cc5053caf38f04e0665f7f88cb109144d035e`、v8 冻结五工况电芯级5折测试 ID、六维可测 CC/CV 特征、源模型与标准化系数不变。
- 每折只在目标训练候选池中选2个标注电芯，使用 v9 归档的 **同一批 Random 5次重采样** 与 Pred-quartiles 一次确定性选择；不根据测试容量改选。
- 新标注预算是每个被选目标电芯**固定前10/20/30循环真实容量**，而非前25%完整寿命。读取训练候选池每电芯前12循环无标签充电统计特征选样；全部真实容量仅允许用于被标注电芯的前N循环。
- 对每个固定选样ID、预算N比较：源模型不校准、仅容量**mean residual offset** (2电芯各等权)、**residual Ridge(alpha=10)**。源模型的全部输入/输出固定；只有标注量及校准方式变化。
- 输出：每目标工况每测试电芯的全寿命容量MAE(mAh)、各折标签ID、Random5次与确定性方法的宏平均；不把随机重复当作独立电芯。
- 所有超参数在运行前冻结；该协议不测试新主动学习方法、不针对3C调参。
- 特别申明：真实XJTU逐循环容量估计，不是Che 2025部分V(Q)或电极物理latent验证。

在运行结果之前创建本记录；后续若要严格确认，应在**新的目标数据/没有参与v8-v9方法筛选的电芯**上预先冻结一种策略。
