# v8 主线冻结协议：RW 源域 → 多目标工况少样本容量/SOH 估计

**状态：研究方向和实验协议冻结（2026-10-08）；本文件不代表 v8 实验已经运行。**

## 研究目标

聚焦一个可完成的硕士论文问题：

> 在随机运行工况（RW）电芯上训练模型，当目标电芯换到不同固定/变化工况时，能否仅标注极少量目标电芯，利用可测的充电特征与代表性选样，实现稳定、低成本的电池容量 / SOH 估计？

**限定**：本项目所用 XJTU/PINN4SOH 数据中的 RW 是*随机运行工况*，与 Che et al. (Joule 2025) 的*随机截取充放电曲线片段*是不同概念。本方向借鉴物理引导与局部数据使用的思路，但不声称在 XJTU 已复现 Che 的四电极隐状态模型。

## 研究范围（减少复杂度）

- **唯一源域**：XJTU `RW_battery-1..8`，该组所有源电芯可提供完整训练标签。
- **目标域**：`3C`（先完整验证）、`2C`、`R2.5`、`R3`、`Sim_satellite`。不开展反向 `3C → RW`。
- **数据**：Wang et al., *Nature Communications*, 2024, PINN4SOH 公开的 55 个 NCM 电芯逐循环特征 CSV（原仓库 Git commit 固定为 `cc3cc5053caf38f04e0665f7f88cb109144d035e`）。
- **主要任务**：每循环*放电容量估计*，MAE 单位 mAh；如转成 SOH，必须有数据文档可追溯的统一额定容量定义，**不利用测试电芯的真实首循环容量归一化**。
- **输入**：首轮固定此前试验的六项可观测充电信息：`voltage mean`、`CC Q`、`CC charge time`、`current mean`、`CV Q`、`CV charge time`。它们是“物理相关可观测特征”，不是 Chen/Che 的电极真实隐状态。
- **创新点只保留一个**：利用目标域**无标签的可观测充电特征**，挑选代表电芯进行少样本标注，随后实施非常轻量的容量残差校准。

## 主实验（RW → 5 targets）

1. 固定公开数据源和电芯 ID。任何一次划分以**电芯为单位**；严禁同一个电芯跨监督训练、模型选择、测试集合。
2. 每个目标域做固定的电芯级外层五折测试；所有方法共享**相同的测试电芯**。验证和模型选择只使用目标训练候选池中被标注的电芯。
3. 单独在 RW 8 电芯上训练源模型。目标未标注候选池可用于确定代表性样本，但不能包含外层测试电芯。
4. 主标签预算：**目标训练候选池内标注 2 个电芯的前 25% 寿命循环容量**。读取未标注候选电芯最前面的 12 循环可测特征用于无标签选样；选样不能用任何容量标签。其余标签不允许参与训练、停止准则或超参数选择。
5. 对照方法（同样标签和测试电芯）：
   - `Source-only`：RW 训练，直接预测
   - `Random + residual Ridge`：随机选 2 个电芯，做残差校准
   - `Representative + residual Ridge`：物理相关充电特征表征下的代表性选样 + 同一校准器
   - `Source SOH/capacity summary cluster + residual Ridge`：输入特征选样的必要简化对照，检验物理选样额外价值（前提是该摘要可在未标注情况下计算，不能用真实容量标签）
6. 适度消融：只改变标注电芯数 1/2/4；容量标签比例 10%/25%。**不引入其他复杂网络或多个迁移方向**。
7. 评价单位：先逐测试电芯汇总 MAE，再逐外层 fold 汇总，最后报告每目标工况和所有目标工况的均值与分布；重复随机种子只反映抽样随机性，不冒充独立电芯数。
8. 超参数在测试前固定或仅由训练划分内进行选择；不能根据测试折对五个目标工况分别挑最优算法。
9. 3C 的 v7.2 12-cell pilot (`42.896 → 32.928 mAh`) 仅作为先验动机。正式完整样本研究可能推翻它，**不预设所有目标域必然提升**。

## 完成标准

- **首要**：独立全样本 55-cell、RW→五目标工况表格，可复算的固定 fold ID、抽样清单、代码/依赖与 per-cell 预测。
- **次要**：少标签成本—误差曲线；与 random selection、源模型零样本的成对比较。
- **创新判断**：如果“代表性选样”在多目标工况和独立外层电芯上稳定优于随机选样，才考虑把方法写成硕士论文的正式贡献；否则只报告实证结论，不强行论证提升。
- **本文不主张**：这项 XJTU 实验验证了 Che 模型的四种电极隐变量、跨化学体系物理状态一致性或动态端电压。

## 执行顺序

- Phase A：仅 RW→3C 全数据，审核与 v7 pilot 的差异。
- Phase B：固定参数直接复用于 RW→2C/R2.5/R3/Sim_satellite，不按测试结果重调。
- Phase C：1/2/4 个标注电芯与 10%/25% 标签预算消融，绘图与统计；写硕士论文方法章和实验章。
- 历史 v3–v7 保留供追溯，**v8 为当前聚焦研究主线**。
