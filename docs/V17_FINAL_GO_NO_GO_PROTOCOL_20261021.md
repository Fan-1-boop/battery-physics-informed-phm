## 唯一新方法：不带二元开关的全局+局部统一核残差

固定源模型RW8六维充电特征Ridge(alpha=1)、固定RW标准化/裁剪、原v10选样2块目标训练电芯和前N循环真容量。

`r_L=y_L-f_RW(X_L)`, `w_i=1/(2N)`, `K_X(i,j)=exp(-||z_i-z_j||²/(2*6))`.

设**只有一种候选新核**：`K_GL=1 + K_X`（常数核+已证实可运行的v14局部RBF-X），统一正则系数不调整`rho=0.05`（沿用v14），直接求：
`alpha=(K_GL+rho diag(1/w_i))^{-1} r_L`;
`Qhat=f_RW(x)+(1+k_X(x,X_L))@alpha`.

这在**一个连续回归函数中**学习全局常数残差与局部残差；当标注残差为0时为零校准，无需训练是否校准二分类器；其它情况下可出现弱/强修正。其核、常数核叠加、KRR理论早有前人工作，因此**仅当实际方法超越强基线且能证明应用层特殊性时才可作为进一步创新候选**，不得说发明常数核/RBF或KRR。v12 LOCO,v14 XQ,v15分歧的已失败方法仍保留为历史消融，不参加后验最优选择。

## 预先固定的、必须照执行的去留门槛

**核心统一校准方向 GO 需同时满足全部：**
1. N30四分位**新Global+Local**的三cohort等权nominal nMAE至少比Ridge低**0.5百分数点**（absolute pp）；并且对应配对bootstrap差`Ridge−GlobalLocal`95%描述性区间下界>0。
2. 至少**2/3**个全新cohort的新校准不高于Ridge的nMAE；任何cohort不得比Ridge差**1.0 pp以上**。
3. 新校准相对源模型的负迁移电芯数不得高于Ridge；且N20四分位与N30随机两组的新校准宏nMAE不得都明显比Ridge更差（超过0.5 pp）。
4. 即便通过，只有“值得继续做理论分析和真正同协议近五年强基线复现”的科研GO，并非已证明相对AT-GPR、复合核GP有算法原创性。

**若统一校准失败，代表性选样是否值得独立保留为硕士论文核心，则另作 GO 判断：**
1. N30在同样旧Ridge方法下，四分位比随机均值至少改善**0.2pp nominal nMAE**；
2. 至少**2/3**新cohort同方向改善；
3. 所有真测试电芯配对探索bootstrap `RandomRidge−QuartileRidge` 的95%区间下界>0。
4. 并须尊重已有v10四分位vs随机并不显著、随机5次部分重复候选组合的事实，不得把一次正结果标成已证明普适主动学习算法。

**最终强制判定：** 若以上两套都不满足，则本“RW固定源+预测容量分位选电芯+统一校准”方向**不建议继续作为硕士论文主算法创新方向**。可以保留为跨工况小标注数据成本与负迁移对比实证章节，但停止继续迭代核/gate公式，转向其它更具可证创新空间的论文方向。若只代表性选样过关，则**缩为单一选样创新**，放弃复杂校准创新。若校准过关，则继续该统一校准思路，但也必须明确KRR+constant本身不原创、仍需强基线复现。
