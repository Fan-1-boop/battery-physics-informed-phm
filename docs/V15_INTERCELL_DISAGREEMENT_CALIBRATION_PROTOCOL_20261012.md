# v15 统一连续校准：标注电芯间残差分歧约束（2026-10-12，开发集预设）

**执行顺序**：本文在本轮首次运行真实 v15 数据前提交。v8–v14 已反复使用同一 XJTU 47 目标电芯，故 v15 不是首次接触数据的独立确认，也不是可用的严格预注册。必须报告全量成功和失败，不可针对结果调公式。

## 背景与文献边界

v14 在原 v8 RW 源模型、固定 v10/v12 标签预算下，RBF-X 校准已有小幅收益，但3C高度核相似的heldout电芯仍出现负迁移；RBF-XQ输出引导核在六组对照全部不及RBF-X。此前 v12 “两电芯LOCO全局缩放”也失败。用户确定的是**一个连续统一校准函数**，其零、弱、强校准都是单一估计函数的输出，不希望另外训练校准/不校准分类器。

前人近5年方向：
- AT-GPR, IEEE TTE 10(1):1080–1088, 2024 (online 2023), DOI 10.1109/TTE.2023.3266499；自适应 GP 任务相似性迁移。
- Xiong et al., Applied Energy 401 (2025), 126762, DOI 10.1016/j.apenergy.2025.126762；复合核稀疏GP迁移与不确定性评估。
- 2026 Neurocomputing `Gaussian process regression via coefficient control for cross-domain SOH estimation` (PII S0925231226023854)；强调样本依赖系数与抑制负迁移，具体实现/发表细节应重新核实。
- 以上已有 GP、核局部迁移、样本依赖权重、收缩/分歧思路，v15 不是原创不确定性理论或已实现文献方法的精确复现。

## 唯一待验证的新机制

基础源模型 `f_RW` 与 v14 RBF-X `g_all` 均保持不变。对已经选择的 **两块**目标标注电芯，分别使用同一6维、源尺度、RBF核、固定正则 `rho=0.05` 拟合两个单电芯残差核估计器 `g_1(x)` 和 `g_2(x)`，每块电芯内`w_i=1/N`（对应各自目标风险权重1）。两电芯合并核模型仍用各自`w_i=1/(2N)`，与v14一模一样。

定义可观测预测分歧 `u(x)=|g_1(x)-g_2(x)|/2`。**固定、不调参**的经验收缩强度：

`lambda(x) = [g_all(x)^2]/[g_all(x)^2 + u(x)^2]`，当分母<=`1e-20` Ah²时定义lambda=0。

`Qhat_v15(x) = f_RW(x) + lambda(x) * g_all(x)`.

- 同一连续公式包含`lambda≈0`的近零校准、0到1中间弱校准、`lambda≈1`的强校准；没有任何额外分类器或fold/domain-specific规则。
- lambda计算只调用被选2电芯各自前N循环真实容量的残差、源模型及待测循环当时可测6个充电统计特征；对待测电芯任何容量真值、未来容量信息零访问。
- `u(x)`是两电芯估计间的**经验分歧指标**，不是有频率学或贝叶斯覆盖概率保证的“置信区间”；`lambda`是基于信号/分歧比构造的候选函数，不是无偏oracle可靠性判别器。即使`g1≈g2`，二者仍可能在新电芯上一起错，v12已提示这种失败模式。
- v14的`rho=0.05`、核尺度/六维特征、源模型完全冻结；**不再同时试新的距离、带宽、gamma、标签选样、阈值、超参、3C专用公式**。

## 冻结实验设计和结果边界

- 原始原作者XJTU数据固定PINN4SOH Git commit `cc3cc5053caf38f04e0665f7f88cb109144d035e`；源 RW8 训练；目标 2C8/3C15/R2.5(8)/R3(8)/Sim_satellite(8) 共47；6个统计特征，放电容量(Ah测量，报告mAh MAE)。
- v8电芯级五折+v10选样：目标训练池每折2块已标注电芯，`pred_quartiles`一次 vs `random`五重复，两个电芯前N=10/20/30循环容量标签，共20/40/60个真实容量观测。所有预算与选样预先全量报告，不将随机重复算成新电芯。
- 重点N30四分位，必须同时给其它五个组合结果。源模型、offset、v10 Ridge、v14 RBF-X与新v15分歧收缩对比；RBF-XQ历史失败消融保留链接但不是v15新实验主线。
- 读数：每目标电芯等权、5工况等权全寿命容量MAE；对源模型负迁移的目标电芯数；新方法和RBF-X差异；lambda在源域与目标域分布；3C的高相似度失败折。
- 核验 v14各测试电芯`source`/`ridge`/`offset`/`RBF-X`以及历史选样ID、fold、原始CSV SHA；阈值 `1e-6 mAh`，修改原始数据/折不允许。测试容量仅用于最后打分。
- 只进行**一次固定公式**的开发集检验；若五域宏MAE或3C负迁移没有稳定收益，归档为失败，不能用v13基于完整测试真值的Oracle当真实方法。
- N10基于候选前12个无标签循环选样，10个早期容量标签如果没有前置保留无法事后补测，不能直接宣称10循环完全前瞻在线落地。
- 论文创新需额外未见电芯独立验证及前人强基线同标签预算对比；此处不宣称SOTA或GP新方法原创。

## 明确可证伪的预期

如果两块标注电芯的残差校准意见分歧对跨电芯泛化具有可识别价值，v15在不增加容量标签的条件下，应较v14 RBF-X降低至少部分负迁移损失，而不严重牺牲已有4工况正迁移收益。如果v15仅因普遍压缩修正使五域MAE上升，判定这一分歧估计不足以成为统一校准框架的可靠核心。
